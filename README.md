# versio-desmodus-navigator

travelers guide for haunting the void: a one-page reference for **desmodus versio**, the noise engineering stereo tail-generator reverb that ships on every versio. every knob by its number on the real panel, the key controls drawn out, both switches, the button, patches and specs.

source: the noise engineering desmodus versio manual.

part of the [versio starsystem](https://mellotom.github.io/versio-navigator/) in the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

not affiliated with noise engineering.
